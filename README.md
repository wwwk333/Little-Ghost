《末日求生 · 寂静居民楼》 玩家攻略手册

📖Read Me

这是一款末日生存文字冒险游戏。
你的每一个选择都会影响后续走向。

本章共有：
  · 5 个死亡结局
  · 2 个正常章节结局
  · 1 个隐藏彩蛋
  · 5 条逃生情报

死亡不是终点，一切能够重来。

本手册不剧透具体结局，只告诉你能怎么走。



🗺️ 剧情分支概览

1.🛏️ 开场

【第一层选择 】


**A. 检查门窗**
  ├─ 保持静默
  │    └─ 🍳 清点物资
  │         ├─ 出去 → 🚪 主线
  │         └─ 留守 → 💀 结局：存活？
  │
  ├─ 窗边观察
  │    └─ 📌 情报 +2 → 🍳 清点物资
  │
  └─ 回看对面阳台
       └─ 🥚 彩蛋 → 🍳 清点物资


**B. 给爸妈打电话**
  ├─ 检查门窗 ──────→ 合并到 A 
  │
  ├─ 清点物资 ──────→ 🍳 厨房
  │
  ├─ 联系老孙
  │    └─ 去老孙家（概率判定 · 五五开）
  │         ├─ ✅ 成功 → 🌞 **老孙线**（入队 + 斧头）
  │         └─ 💀 失败 → 结局：迎面而来
  │
  └─ 大声呼救 ──────→ 合并到 C 


**C. 大声呼救**
  └─ 阳台搏斗（概率判定 · 凶险）
       ├─ ✅ 成功 → 📌 情报 +1 → 🍳 清点物资
       └─ 💀 失败 → 结局：天降之喜


2.🍳 清点物资


**水源：充足 · 食物：充足**

  ├─ 做好准备出去 ──→ 🚪 主线：老孙敲门
  └─ 留守家中 ──────→ 💀 结局：存活？（物资耗尽）


3.🚪 主线·老孙敲门

**A. 开门**（概率判定 ）
  ├─ ✅ 成功 → 老孙入队 → 👧 林晓雨事件
  └─ 💀 失败 → 被迫击杀老孙 → 👧 林晓雨事件

**B. 隔着门问清楚**
  └─ 📌 情报 +1 → 👧 林晓雨事件

**C. 不开门，装不在**
  └─ 👧 林晓雨事件


4.👧 主线·林晓雨事件

  ├─ 制造声音引开感染者 → 🏠 对面楼求助
  └─ 不管闲事，等安静 → 🏠 对面楼求助

>     如果开局选择"回看阳台"，可以看到她最后的痕迹



5.🏠 主线·对面楼求助事件


  ├─ A. 不管闲事
  │    └─ 🏢 **留守线**
  │         └─ 上楼遇感染者（概率判定）
  │              ├─ ✅ 一刀成功 / 有斧头直接过 → 林晓雨家
  │              └─ 💀 失败 → 结局：勇气是人类的赞歌
  │
  └─ B. 等天黑去帮忙
       └─ 🌙 **救助线**
            └─ 上楼遇感染者（概率判定）
                 ├─ ✅ 一刀成功 / 有斧头直接过 → 林晓雨家
                 └─ 💀 失败 → 结局：勇气是人类的赞歌

11.🪓 装备与耐久

  · **斧头**（上限 6 点）
    全章最多消耗 4 点，**不会损坏**
    消耗点：上楼砍感染者 -1
             开卧室电子锁   -2
             夜路硬闯       -1
    ★ 拿到斧头 = 跳过两次致命判定

  · **警棍**（留守线获得）
    本章不消耗耐久，仅作收藏
