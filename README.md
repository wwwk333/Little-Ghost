# 末日求生 · 寂静居民楼

这是一款末日生存文字冒险游戏。
你的每一个选择都会影响后续走向。

- **游戏类型**：文字冒险 / 生存 / 多结局
- **游玩时长**：约 15–25 分钟
---

## 🎮 在线游玩

直接点击下方链接即可开始游戏（推荐使用 Chrome / Edge / Safari）：

👉 **[点击开始游戏](https://<你的用户名>.github.io/<你的仓库名>/)**

> 💡 **提示**：

1.可查看 📖 玩家攻略手册

手册提供分支路线图、逃生情报一览与装备说明，**不剧透具体剧情**

👉 **[点击查看玩家攻略手册](./玩家攻略手册.md)**

3.💻 源码

游戏源码为单个 HTML 文件，包含全部逻辑、样式与剧情数据。

- 最新版：[末日求生 · 寂静居民楼_v1.0](<./末日求生 · 寂静居民楼_v1.0.html>)

如果你想本地运行：
1. 下载 `Index.html`或v1.0代码HTML到本地。
2. 确保同目录下有 `images/` 文件夹和所有 `.mp3` 音频文件。
3. 双击 HTML 文件即可在浏览器中游玩。
